# P5: Semantic bio page

A short personal introduction built with semantic HTML elements.

## What I practised

- Use header, main, section and footer elements.
- Write a short introduction.
- Add a few interests and learning goals.
- Keep the page readable on a phone.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.

## Notes

This is a practice exercise. I can change the text, colours and layout as I learn more about the topic.
