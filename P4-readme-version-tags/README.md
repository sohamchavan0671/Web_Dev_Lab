# P4: GitHub README and version tags

A project README example and a short note about tagging a release.

## What I practised

- Write a README that explains the project.
- Include setup and run instructions.
- Create a version tag after a working milestone.
- Push the tag to GitHub.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.
