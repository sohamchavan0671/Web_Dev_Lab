# P7: Design tokens and typography system in CSS

A small style guide using CSS custom properties for colours, spacing, type and reusable elements.

## What I practised

- Define colours and spacing as CSS variables.
- Set a consistent type scale.
- Reuse the same button and card styles.
- Change a token once and see it update across the page.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.

## Notes

This is a practice exercise. I can change the text, colours and layout as I learn more about the topic.
