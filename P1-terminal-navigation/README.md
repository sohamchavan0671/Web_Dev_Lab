# P1: Project folder and terminal navigation

A small practice page for the folder structure and terminal commands used at the start of a project.

## What I practised

- Create a folder for the portfolio project.
- Open that folder in VS Code.
- Use pwd, ls and cd to move around the project.
- Keep the files in one clear place.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.

## Notes

This is a practice exercise. I can change the text, colours and layout as I learn more about the topic.
