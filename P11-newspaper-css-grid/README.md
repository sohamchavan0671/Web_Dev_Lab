# P11: Newspaper-style three-column layout with CSS Grid

An editorial page using a three-column grid for a lead story and supporting notes.

## What I practised
- Creating columns with CSS Grid.
- Giving the main story more room.
- Reducing the number of columns on smaller screens.

## Files
- `index.html` – article content and structure.
- `style.css` – grid and responsive styles.

Open `index.html` in a browser.
