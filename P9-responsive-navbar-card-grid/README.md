# P9: Responsive navbar and card grid using Flexbox

A responsive navigation row and a set of cards built with Flexbox.

## What I practised
- Aligning navigation links with Flexbox.
- Letting cards wrap on smaller screens.
- Using flexible card widths instead of fixed columns.

## Files
- `index.html` – content and structure.
- `style.css` – external styles.

Open `index.html` in a browser and resize the window.
