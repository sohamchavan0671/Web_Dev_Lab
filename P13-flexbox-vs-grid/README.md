# P13: Choosing between Flexbox and Grid for a shared layout

A side-by-side example of two common CSS layout tools.

## What I practised
- Using Flexbox for one-dimensional alignment.
- Using Grid to arrange content in rows and columns.
- Comparing the two approaches on one page.

## Files
- `index.html` – both layout examples.
- `style.css` – external styles for the examples.

Open `index.html` in a browser and compare the two demos.
