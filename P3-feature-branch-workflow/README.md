# P3: Feature-branch Git workflow

A simple page documenting a feature branch workflow and the steps used to merge work.

## What I practised

- Start from the main branch.
- Create a separate branch for a feature.
- Make and commit the change on that branch.
- Merge the finished work back into main.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.
