# P6: Full portfolio page structure in semantic HTML

A complete portfolio layout with sections for an introduction, skills, projects and contact details.

## What I practised

- Build the page using semantic HTML landmarks.
- Add navigation links to page sections.
- Create skills and project sections.
- Add a contact section and footer.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.
