# P2: Portfolio repo with an initial commit

A basic portfolio landing page to keep as the first version in a Git repository.

## What I practised

- Create a repository for the portfolio.
- Add the first HTML and CSS files.
- Stage the files and make an initial commit.
- Push the repository to GitHub.

## Files

- `index.html` – page structure and content.
- `style.css` – styles kept separately from the HTML.

## Run it

Open `index.html` in a browser. No installation is needed.

## Notes

This is a practice exercise. I can change the text, colours and layout as I learn more about the topic.
