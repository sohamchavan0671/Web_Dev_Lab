# P8: Sticky navbar and card overlay using CSS positioning

This exercise uses a sticky navigation bar and a label positioned over a feature card.

## What I practised
- Keeping the navbar visible with `position: sticky`.
- Using `position: relative` on the card.
- Placing a badge with `position: absolute`.

## Files
- `index.html` – page structure.
- `style.css` – all styling, kept external.

Open `index.html` in a browser and scroll to test the navbar.
